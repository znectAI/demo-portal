# Requirements

`requirements.md` is the signed-off record of what the client asked for, written by the znectAI
requirements agent from the client's people and signed off by the business owner. It reaches
`main` only through a PR opened at sign-off; merging it makes it the record (tag
`requirements-vN`).

No pipeline agent may change this folder. A change to the requirements is a new signed-off round,
which arrives as a new PR showing exactly what changed.
